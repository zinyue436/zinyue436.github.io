## Maintain the website

The website uses plain HTML, CSS, and JavaScript with no build step.

- `index.html`: profile, publications, research experience, projects, and education.
- `styles.css`: colors, typography, and responsive layouts.
- `script.js`: mobile navigation and active section highlighting.
- `evipathbench.png`: research overview figure.

Open `index.html` to preview locally, or run `python3 -m http.server 8765 --bind 127.0.0.1` in this directory.

GitHub Pages serves the `main` branch from the repository root. See [GitHub Pages documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).
